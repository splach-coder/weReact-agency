# Marketplace commissions charged to tour operators and riads (read 10 Nov 2026)

Method: for each platform I looked for the platform's **own** supplier/host page first (live page, fetched
10 Nov 2026). Where the live page states no figure, I say so. Where an earlier version of the official page
did state a figure, I quote it from the Internet Archive (Wayback Machine) with the snapshot date, labelled
"official, archived". Third-party figures are listed separately and labelled. Raw copies of the pages I read
are in `study/commission_raw/`.

Bottom line, official only: **Airbnb is the only platform that publishes its rates on a live page
(3 % split / 15.5 % host-only for homes, 20 % for Experiences).** GetYourGuide used to publish 20–30 % and
has taken the number down. Viator, Booking.com and Expedia do not publish a percentage; the rate is in the
contract or shown during sign-up.

## C. Notes and limits
- Viator's operator site (operatorresources.viator.com) and viator.com support pages returned HTTP 403 /
  a Cloudflare challenge to automated requests; I did not try to get around it and used Internet Archive
  copies instead (snapshot dates given above).
- One third-party page (lodgify.com, Expedia fees) returned HTTP 403 and was not used.
- Two Ventrata help articles that search results quoted for Viator/GetYourGuide ("typically 20-30%") now
  return HTTP 404, so they are not cited.
- Search-engine summaries attributed figures to some pages (e.g. Skift on Viator Accelerate tiers) that the
  pages themselves did not contain when fetched; those figures are not used.
- Airbnb's page was served with MAD as display currency (request from Morocco); the percentages are the
  same text as the global article. The page says it is "transitioning all home hosts to a single service fee
  structure", so for a riad the split fee may no longer be available.
- Booking.com's 2023 Moroccan press figures concern classified hotels (FNIH dispute); they are not a
  Booking.com statement.
