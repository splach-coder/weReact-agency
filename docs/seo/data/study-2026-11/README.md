# Study data — November 10, 2026

- `summary.json`: aggregate counts behind the article
  [Agences web à Marrakech : ce que montrent 66 sites](https://www.wereact.agency/fr/blog/etude-sites-agences-web-marrakech).
  Per-site rows (which name the agencies) are kept off this public repository on purpose; the owner has a local copy.
- `commissions.md`: every platform commission figure used in
  [the commissions article](https://www.wereact.agency/fr/blog/commission-getyourguide-viator-booking-maroc), with the exact quote,
  URL, date read, and whether it is official, archived or third-party.

Method: Google Morocco, French, desktop; top 20 organic results plus the map pack for "agence web marrakech",
"création site web marrakech" and "agence seo marrakech", each read three times and merged. For each agency or freelancer
site, the ranking page and the homepage were fetched once each (robots.txt respected, no JavaScript run); prices,
delivery times and reviews were checked by hand.
